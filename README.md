# Kora
Navigateur + gestionnaire de téléchargements, sans publicité.
1. Envoyer ce dossier sur GitHub, onglet Actions > build > Run workflow.
2. Récupérer l'APK dans les artefacts (Android).
3. iOS : signer avec un compte Apple Developer (Xcode ou Codemagic), puis App Store Connect.
Windows : webview_flutter ne le gère pas ; utiliser le paquet webview_windows ou Electron.
